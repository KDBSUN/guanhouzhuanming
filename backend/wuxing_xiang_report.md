## 三、最终库结构（backend/wuxing_xiang.json）

- `meta`：来源与合并规则说明。
- `wuxing`：木火土金水 × 29 维度（数/方位/四时/干支/五色·间色/五味/五臭/五音/五声/五常/五事/五脏/六腑/开窍/五畜/五谷/五果/五菜/五星/五帝/五神/五志/八卦/人物形貌/人物性情/物象(王相休囚死)/职业方向）。
- `bagua`：八经卦万物类象（五行/方位/八节/先后天数/人伦/动物/身体/类象/静物/屋宅/饮食/五色/五味/数目）。
- 无 `extra`（已删）。

## 四、建议生成函数（backend/wuxing_suggest.py）

```python
from wuxing_suggest import suggest_wuxing, suggest_text

data = suggest_wuxing(["木", "水"])   # 结构化建议 dict
md   = suggest_text(["木", "水"])     # Markdown 文案
```

按"待补五行 → 方位 / 颜色 / 数字 / 物件 / 饮食 / 职业 / 健康 / 卦象 / 屋宅 / 四时干支"输出。
建议输出层（补五行建议）调用 `suggest_wuxing(待补五行列表)` 即可；文案版 `suggest_text` 可直接进 AI prompt 或页面展示。
