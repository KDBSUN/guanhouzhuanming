## 二、生成方式（可重复执行）

```bash
cd backend
node tools/extract_term_maps.mjs ./data     # 抽取 4 份 HTML 内嵌的 JS 数据字面量 → data/term_maps_raw.json
python tools/build_terms_db.py              # 合并 + 浓缩层 + 覆盖层 → 建库 + 报告
python -m pytest tests/test_terminology.py tests/test_prompt_b_batch.py -q
```

产物：`terminology.db`、`data/terminology_merged.json`（合并快照）、`data/term_condensed.json`（浓缩文案）、`data/term_overrides.json`（补录与校正）、`data/terminology_report.md`。
抽取脚本只读原始 HTML，**不改动** `D:\360Downloads` 与书籍文件；仅在内存中修复源文件的语法引号（见第四节 1）。

## 三、加工管线（v2 新增两层）

1. **合并层**：梅花以 `tabbit-code.html` 为骨架，同名归一并条（68 条），另两份的独占词条并入。
2. **浓缩层**（`data/term_condensed.json`）：全部 148 条梅花释义按六爻地图的密度统一浓缩（role ≤14 字；detail ≤110 字；只压缩不改事实，数字/卦名/口诀关键词保留）。
3. **白话层**（`data/term_plain.json`，v3 新增）：可见词条释义再按《六爻术语知识地图》基础版语体改写——一句白话 20～45 字，无文言腔，面向初学者。
4. **覆盖层**（`data/term_overrides.json`，最后应用）：
   - **补录 4 条占例**（据《增广校正梅花易数》原文）：牛哀鸣占（21 日）、鸡悲鸣占（10 日）、枯枝坠地占（10 日）、少年有喜色占（17 日），连同已有的老人有忧色占（5 日取半）、观梅占（次日）共 6 条带应期数字的运算实例——占例类整体默认隐藏，需要时在库中备查；
   - **改正 3 处**：夏艮兑→夏乾兑（删含错合并条，保留正确的卦气旺/卦气衰两条）；体克用小吉→诸事吉（五行生克、体用生克之诀两条）；十七占/十八占统一为「十八占（十七占）」；
   - **加 2 处两书分歧注**：卦身（野鹤弃用 vs《卜筮正宗》保留）、长生十二宫（《正宗》"三件" vs 合《增删》"化帝旺"的"四位"综合）；
   - **近重复词条合并 30 对**（三要 vs 三要灵应、体用生克 vs 体用生克之诀、八宫五行 vs 八宫所属五行、各种"合并版 vs 拆分版"等）：败者关联并入胜者、旧名入别名、关联按别名解析；
   - **隐藏 37 条非术语内容**（占例 11、测字指迷 11、书论与总诀 6、观物克应的歌诀赋文 7、戒律 1、多余说明 1）。

## 四、源文件缺陷清单（只读检查所得，未改动源文件）

1. **`tabbit-code.html` 有语法错误 → 该页在浏览器里根本渲染不出来**：`detail:"…为什么梅花可以有那么多"随时取物"的起卦法。"` 使用了未转义的英文双引号，整个 `<script>` 块报 SyntaxError 失效（共 2 处）。抽取时已在内存修复，未回写文件。
2. **`tabbit-code.html` 有 6 处关联指向不存在的 id `wanwu`**（实际 id 是 `baguaXiangli2`「八卦万物属类」）：八宫所属五行、八卦象例、端法后天起卦之例、八卦心易体用诀、诸事响应歌、十七占。原页面这些关联按钮会静默消失；入库时按上下文修复为「八卦万物属类」。
3. **`梅花易数术语知识地图.html`（初版）有 1 处悬空关联**：先天起卦法 → 先天后天论（该文件无此词条）。入库后因骨架含该词条而自动解析成功。
4. **`梅花易数术语知识地图.html`（初版）内容错误**：卦气衰写作「春坤艮、秋震巽、**夏艮兑**、冬离、四季月坎」——按《梅花易数》应为「夏**乾兑**」衰（火旺克金；艮为土，夏为相不为衰）。已通过删除该含错合并条、保留正确两条处理。
5. **占例词条把多个验例并成一条、且丢了关键数字**：(1) 版把「少年有喜色占、牛哀鸣占、鸡悲鸣占、枯枝坠地占」压成一条——已按书原文补成 4 条独立词条并注应期数字。
6. **命名不一致**：初版作「十七占」、(1) 版作「十八占」——已统一为「十八占（十七占）」。
7. **断语取舍不一致**：`tabbit-code.html` 写「体克用**小吉**」，(1) 版写「体克用**诸事吉**」。按《梅花易数·体用总诀》原文为「体克用，诸事吉」——已统一。
