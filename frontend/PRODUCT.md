# Product

## Platform

web

## Users

两类用户并重，无主次之分：

- **术数占卜使用者**：对梅花易数、纳甲六爻、四柱八字、奇门遁甲、大六壬等传统占法有兴趣的人，用它辅助做决定、了解自身命局。使用方式是「一事一占」，起卦前静心默念所问，先过命局校验再选占法。
- **术数文化研究者**：关注传统术数、易学、命理的典籍溯源、术语准确性、跨域考证的人。对应「术语地图」与「移植行星」（卷九）这类长文研读入口。

## Product Purpose

把传统术数典籍做成可交互、可回溯的工具。六门占法（梅花易数、纳甲六爻、四柱八字、奇门遁甲、大六壬、紫微斗数）各自起卦、排盘、解读；每一条判定都标注典籍出处，点开即可核对原文。产品自述见页脚：「以传统术数典籍为规则底本的行动辅助工具：卦象给方向，八字画边界，每一条建议都可回溯到原文。」

## Positioning

**行动辅助为主，娱乐/文化声明为辅。** 产品机制是「术数规则可执行化 + 可回溯原文」——这是同类占卜产品不能凭空的定位：不是给一句结论，而是给出「哪个卦/哪一柱/哪条规则推出了这句话，出处在哪里」。同时，页内与页脚固定声明「纯属猜想，仅供娱乐」「不构成任何建议或预测」「所涉内容未经现代科学验证」，并引导用户遇到实际难题通过社会途径求助。

## Operating Context

- 一事一占：一次只问一件具体的事（页脚《使用指南》原话）。
- 八字命局先行：先校验命局，再选占法；红线处自动改方。
- 占卜使用与术数研读共用同一套术语体系（术语地图）。
- 排盘为纯计算，不消耗 AI 额度；AI 解读另走接口。

## Capabilities and Constraints

**已实现（代码确认）**：

- 导航入口：首页、八字（命局先行）、占卜（梅花易数 / 纳甲六爻 / 奇门遁甲 / 大六壬）、研读与探索（术语地图 / 移植行星）、我的与设置（我的记录 / API 设置 / 公测反馈）。
- 四柱八字排盘（BaziView）：四柱、十神、藏干、纳音、地势、自坐、旬空、干支体性、五行分布、格局、调候、喜忌、大运流年、命宫胎元，均为纯计算。
- 记录回放：把存档快照还原到对应占法页，不重新起卦、不产生新记录。
- 首页黄历条：调 `/api/huangli/today`，取不到时如实降级为占位标记，不编数字。
- 「移植行星」（卷九）长文：典籍引文逐字并标篇目与书库编号，学派学说与编者推导单独标注。

**技术约束**：

- React 18 + TypeScript + Vite，哈希路由（`#/meihua` 等），无路由库、无动画库。
- 开发端口 3001；`/api` 由 Vite proxy 转发到 `http://localhost:8000`。
- 只新增/修改 `frontend/`，不改动 `frontend/`、`backend/` 及其他任何目录。

**未定/未接入**：后端全部端点尚未完全对接（v0 占位）；真实用户数据未采集。

## Brand Commitments

- 名称「易占」，副标「白金版」，slogan「观天机 · 断人事」。
- 免责声明为固定文案，不可删改或弱化：「请不要迷信」「纯属猜想，仅供娱乐」「不构成任何建议或预测」「所涉内容未经现代科学验证」「遇到难题请通过社会途径寻求帮助」。
- 术语与典籍引文必须逐字准确，禁止凭记忆改写。

## Evidence on Hand

- 典籍引文均标注篇目与书库编号，如《周易·系辞上》《礼记·月令》《素问·天元纪大论》（见「移植行星」卷九正文）。
- 免责声明固定文案（Footer 与各占法页）。
- 黄历条、八字排盘等数据接口存在但为 v0 占位或部分接入。
- **未查到**：真实用户案例、评测、压测数据——未来工作不得虚构此类内容。

## Product Principles

1. **每条判定可回溯原文**：结论必须能指认出处，读者可点开核对。
2. **宁缺毋假**：取不到数据就如实降级为占位标记，绝不编数字。
3. **准确性优先于通俗性**：用准确术语与事实陈述，不做跨领域类比，宁可平实不可失真。
4. **八字命局先行**：先校验命局，再选占法。
5. **免责贯穿始终**：娱乐/文化研究属性在入口与页脚都明确声明。

## Accessibility & Inclusion

- 触控目标 ≥44px；导航、摇卦、签筹等交互元素均有键盘可达与可见焦点。
- 语义标注：`aria-current`、`aria-expanded`、`aria-controls`、`role="alert"/"status"`、`aria-live`。
- 尊重 `prefers-reduced-motion`：减少动态效果时不做空间位移动效。
